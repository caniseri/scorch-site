Eight screens.
One journey.

Open Scorch, find a scheduled race, start at your time, finish, and choose the next run.

  1. 01
    Open

    Open Scorch

    Create an account and land on Home with one clear answer to what you should run next.

    Pilot routes • Run-only • Free races
  2. 02
    Athlete Profile

    Enter Your 5K Pace

    Add one recent 5K pace so Scorch can calculate your fair start. Fitness imports stay optional in Settings.

    Run 5K pace: 4:00/km • Fair start ready
  3. 03
    Discovery

    Find a Scheduled Race

    Browse nearby scheduled races, or choose an Anytime run when a live field does not fit your day.

    Example pilot route candidate • 9.66 km
  4. 04
    Fair Start

    See Your Fair Start

    Scorch uses race distance and your recent pace to give each runner a fair start time.

    Example offsets: -2:30 • 0:00 • +1:15

    Live Race

    Race the Gap

    The live screen keeps the map, route progress, gap, and useful signal warnings in view while you run.

    Example cue: +12 seconds to target
    Live race
    Gap to leader+0:12

    Finish Detection

    Lock the Finish

    Scorch saves the finish when route progress and the runner's GPS signal agree.

    Finish confidence: High
  7. 07
    Race Results

    Confirm Placement

    Reviewed results separate final rank from raw finish order and explain any result under review in plain language.

    1st: Ready • 2nd: You
